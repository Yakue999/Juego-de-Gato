Hello, this is my first project in Java.
This game is in Spanish, so this guide will help you understand what it is about. 
This project is a Tic-tac-toe game developed on NetBeans and made for a class.
In this case, the game allows players to enter their names and ID (in case they have one) to log in and play.
There is also a menu with 3 buttons: 
1. Jugar -> Play the game 
2. Estadísticas -> See all players stats
3. Salir -> Close the game when you are finished playing
When you choose ¨Jugar", you play as usual, but you can also see the history of every move made.
You can also restart the game when a match is finished to keep playing.
